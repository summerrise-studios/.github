# Contributing to Summer Rise Studios

Thanks for your interest. Svara, Echo, and Frame are early: they're in research, and development is about to begin. Right now the most useful contributions are ideas, feedback, and pointers to good research. Open an issue in the repository it relates to.

## Before you start

- For anything bigger than a small fix, open an issue first so we can agree on the approach before you spend time on it.
- Everyone taking part follows our [Code of Conduct](https://github.com/summerrise-studios/.github/blob/main/CODE_OF_CONDUCT.md).
- Found a security problem? Don't open an issue. Follow the [security policy](https://github.com/summerrise-studios/.github/blob/main/SECURITY.md) instead.

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Keep each pull request to one change, and describe what it changes and why.
3. Make sure it builds and that any tests pass.
4. A maintainer will review it and may ask for changes before merging.
